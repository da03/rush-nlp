Follow the evidence

  • The morning ChatGPT conversation. The opening shows the actual request and a short quotation from its answer.
  • OpenAI’s original Sora examples. The talk uses a ten-second excerpt from the archival papercraft coral-reef video. Original video.
  • NeuralOS paper. The Firefox example was recorded through the same deployed inference service as the public demo. It is a selected observed failure, not an overall accuracy measurement. Persistent memory means retaining changes after they leave the screen. The learning slide compares real predictions from two training stages with their shared recorded target, alongside an illustrative error curve. The Doom example uses edited demonstrations: a pasted icon and launch/exit actions integrate real VizDoom footage. The model result is a generated sequence, with playback timing chosen for presentation.
  • From Explicit CoT to Implicit CoT: Learning to Internalize CoT Step by Step. Training starts with written intermediate steps, then removes them gradually while training continues. The small multiplication example illustrates this curriculum; the separate eight-digit result is a real demo capture. Answer-only training struggled in the reported experiment, which does not establish that learning without written steps is universally impossible. The final model still performs computation. Research code · Original announcement.
  • Program-as-Weights paper. The demos combine neural programs with conventional application code. In the captured letter-counting run, the linked Standard 0.6B program returned 4 for strawberryrr; the exact number of r’s is 5. This is one observed failure, not a claim about every model or input. Original letter-counting post.
  • AskChem paper. AI extracts structured claims from papers and preserves links to their supporting evidence. The talk uses its ibuprofen process claim, supported by the source review and the EPA’s 1997 award account. The comparison is six reaction steps versus three in two historical manufacturing routes, not an AI-designed process. The question about halving production time is an audience reasoning exercise, not a captured model response.
  • EVA-Flow manuscript, Sections 3–4 and Table 4. The model predicts candidate 3D shapes while keeping the supplied atom identities and bonds fixed. The talk’s reference-versus-prediction images come from Table 4; the introductory ibuprofen and butane models are teaching illustrations.
  • SPARK research prototype. The A/B/C reaction snapshots explain the idea of hidden reaction steps; they are teaching illustrations, not measurements or model outputs. The extra-step example is reconstructed from Bing Yan’s supplied slides, which describe a saved app run from October 13, 2026 on a known simulated test case. The talk does not include independently captured raw output for that run or treat it as a benchmark. See the project README for the model’s limitations.
  • SPARK’s supplied RuHex measurement. This experimental example appears only in an optional backup slide. A simulator provides known answers for simulated cases; it does not establish the cause of a real measurement.
  • Yan, Chen & Cho, Digital Discovery (2025). Optional backup: different descriptions of the same molecule can lead to inconsistent language-model answers. Agreement and accuracy require separate checks.
  • WildChat dataset. WildChat is the dataset; WildVisualizer is a website for exploring conversations. Conversations were collected through free chat services on Hugging Face with explicit user consent to collection and public sharing. The talk’s self-contained search example uses crops from the supplied WildVisualizer recording, showing the homework and United States filters and a complete homework-policy request. Watch a prepared photosynthesis search as an extra example. The map recording was shared in May 2024; it is a historical dataset visualization.
  • Andrej Karpathy’s Turing-test meme, December 1, 2024.

NeuralOS and PAW recordings come from the presenters’ research materials. The English verb task, abstract learning diagrams, multiplication curriculum, introductory molecular models and A/B/C reaction snapshots are teaching illustrations.
