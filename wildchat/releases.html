Choose a WildChat release

Match the collection and filtering to the research question.

Start with the open WildChat-4.8M release for most new projects. Use a Full release when the study requires flagged content and access has been approved. For replication, match the repository, revision, and filters used by the original study.

Current downloads and access requests: yuntian-deng/WildChat-4.8M and yuntian-deng/WildChat-4.8M-Full. Request Full access in the latter repository.

Selected collection and release milestones

The original paper describes an approximately one-million-conversation corpus, and some experiments use earlier collection windows. The expanded 4.8M releases cover a longer period and more models. Historical study counts should be read in that context.

Collection dates, paper versions, and dataset updates describe different events. The arXiv version below does not establish the first public release of WildChat.
