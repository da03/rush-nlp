About this guide

Scope and curation

A research home for the dataset and the work it supports.

This guide is curated by Yuntian Deng, a coauthor of WildChat and WildVis. It connects the original contributions, dataset releases, tools, and selected research using WildChat.

What the guide covers

The bibliography is a selected collection, not a complete citation index. Papers are included for a concrete relationship to WildChat: introducing the dataset, enabling exploration, analyzing conversations, building evaluations, or creating training data from it.

Each annotation states how the paper uses WildChat and points to supporting primary sources. Dataset versions and study snapshots are identified where the source provides them. Third-party derivatives are distinguished from newly collected human conversations.

WildVis is a separate research contribution and a multi-dataset tool. This guide links to WildVisualizer for exploration and to the original Hugging Face repositories for data access.

Sources and updates

Publication records, papers, dataset cards, and the processing repository support the descriptions here. Release counts describe the checked repository state; they can differ from a paper’s historical statistics.
